# MU-Nodes-RunningHub

适配 RunningHub 独立上传的 MU 节点包。

所有节点统一显示在 `MU` 分类下。

本包保留 UK 兼容模型节点、上游 Key 兼容的媒体解析节点和 Google/Gemini 节点。

## 安装

将整个目录放入 ComfyUI：

```text
ComfyUI/custom_nodes/MU-Nodes-RunningHub/
```

在 ComfyUI 使用的 Python 环境安装依赖，并重启 ComfyUI：

```powershell
python -m pip install -r requirements.txt
```
